# Factor-Based Investment Strategy Analyzer

Анализатор инвестиционных стратегий на российском рынке акций.
В проекте реализованы десять стратегий: пять традиционных: Passive, Momentum, Value, Growth, Quality; и пять нетрадиционных - Fractal, Network, Anomaly, Low Volatility, Seasonality.
Выходные данные: графики, реализующие сравнение стратегий:
1. График накопленной доходности за общий период
2. График годовых доходностей
3. График Risk/Return
4. График превышения доходности над Passive
5. График Turnover портфеля
6. График среднего пересечения портфелей стратегий

Проект реализован на Python с использованием библиотек `pandas`, `numpy` и `matplotlib` и позволяет:
- Загружать исторические данные о ценах акций и фундаментальные показатели
- Проводить сравнение инвестиционных стратегий
- Сравнивать стратегии по доходности, риску, оборачиваемости и составу портфелей
- Визуализировать результаты через набор стандартизированных графиков

4. Запустите проект: `uv run main.py`

# Реализованные стратегии

## 1. Passive (Пассивная стратегия)
Базовый ориентир для сравнения. Все бумаги включаются в портфель с равными весами.
Не использует фундаментальные показатели, мультипликаторы или прошлую доходность.

## 2. Momentum-стратегия
Momentum-стратегия основана на предположении, что бумаги, которые хорошо росли в прошлом периоде,
могут продолжить показывать относительно сильную динамику в следующем периоде.

## 3. Value-стратегия
Value-стратегия выбирает бумаги, которые выглядят недооценёнными
по фундаментальным мультипликаторам.

## 4. Growth-стратегия
Growth-стратегия выбирает компании, у которых быстрее растут основные финансовые показатели.

## 5. Quality-стратегия
Quality-стратегия выбирает компании с более качественными финансовыми характеристиками:
высокой рентабельностью и умеренной долговой нагрузкой.

# Нетрадиционные стратегии

## 6. Fractal-стратегия

Fractal-стратегия использует [R/S-анализ](https://ru.wikipedia.org/wiki/RS-%D0%B0%D0%BD%D0%B0%D0%BB%D0%B8%D0%B7) для расчёта [показателя Хёрста](https://en.wikipedia.org/wiki/Hurst_exponent) на основе исторических логарифмических доходностей.

Показатель Хёрста используется для оценки персистентности временного ряда:

* `H > 0.5` — персистентное поведение;
* `H ≈ 0.5` — поведение, близкое к случайному блужданию;
* `H < 0.5` — антиперсистентное поведение.

В рамках стратегии акции ранжируются по рассчитанному показателю Хёрста, после чего выбираются бумаги с наиболее высокими значениями показателя.

### 7. Network-стратегия

Network-стратегия рассматривает рынок как сеть взаимосвязей между акциями.

На основе дневных логарифмических доходностей строится матрица корреляций между активами. Затем для каждой акции рассчитывается показатель центральности (`centrality score`), характеризующий её положение в структуре рынка.

В базовой конфигурации используется сумма абсолютных корреляций акции с остальными активами

Также предусмотрена возможность использования `eigenvector centrality` на основе главного собственного вектора матрицы абсолютных корреляций.

В портфель отбираются акции с наиболее высоким показателем центральности.

### 8. Statistical Anomaly стратегия

Anomaly-стратегия ищет необычные движения цен относительно недавнего поведения конкретной акции.

Для каждой акции рассчитываются дневные логарифмические доходности, после чего на скользящем окне определяется медиана и `MAD` (Median Absolute Deviation).

На их основе рассчитывается модифицированный Z-score:

Modified Z = 0.6745 × (Return - Median) / MAD

Для поиска аномальных падений используется инвертированный показатель:

Anomaly Score = -Modified Z

Таким образом, чем сильнее последняя доходность акции отклоняется вниз от её типичного поведения, тем выше её Anomaly Score.

Основной порог стратегии составляет 2.5. Если достаточного количества акций с аномально сильным падением нет, используется fallback-механизм: портфель формируется из наиболее высоких значений Anomaly Score без применения порога.

### 9. Low Volatility-стратегия

Low Volatility-стратегия основана на эмпирическом наблюдении, что акции с относительно низкой исторической волатильностью могут демонстрировать привлекательное соотношение риска и доходности.

Для каждой акции рассчитывается годовая волатильность дневных логарифмических доходностей за последние 252 торговых дня:

Volatility = std(Log Return) × √252

После этого волатильность инвертируется в `LOW_VOL_SCORE`, чтобы использовать единый механизм ранжирования стратегий:

чем ниже Volatility, тем выше LOW_VOL_SCORE и позиция акции в рейтинге


В портфель отбираются акции с наиболее низкой исторической волатильностью.

### 10. Seasonality-стратегия

Seasonality-стратегия использует исторические календарные закономерности доходности акций.

Для каждого периода ребалансировки определяются месяц входа и месяц выхода из позиции. Затем для каждой акции рассчитывается её средняя историческая доходность между этими двумя месяцами.

Например, для периода март -> апрель 2026 рассматриваются результаты:

март -> апрель 2023

март -> апрель 2024

март -> апрель 2025


Текущий год при расчёте score не используется, чтобы избежать использования будущей информации.

Для включения акции в расчёт требуется как минимум три доступных исторических года. После этого акции ранжируются по средней исторической сезонной доходности, и в портфель включаются бумаги с наиболее высоким показателем.
